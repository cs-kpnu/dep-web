# Dep-Web | Платформа цифрової кафедри

## Про проєкт
**Dep-Web** - це цифрова візитка та платформа студентського гуртка стартапів "Цифрова кафедра". 
Проєкт вирішує дві ключові задачі:
1. **Для студентів:** Демонстрація успішних проєктів, знайомство з командою ентузіастів та надання зручної форми для подачі заявки на вступ.
2. **Для викладачів та партнерів:** Єдина точка доступу до портфоліо гуртка та моніторингу його активності.

**Критерії успіху MVP (Поточний статус):**
- [x] Розгортання на staging-сервері.
- [x] Наповнення бази: додано актуальну команду та 5 проєктів портфоліо.
- [x] Успішне отримання перших заявок від студентів через контактну форму.

## Технічний стек
- **Frontend:** Next.js
- **Backend/CMS:** Headless WordPress (PHP)
- **Database:** MySQL
- **API:** REST WP API and ACF (Advanced Custom Fields)
- **Infrastructure:** Docker, Docker Compose

## 💻 Локальний запуск для розробників

Для розгортання проєкту на вашій локальній машині виконайте наступні кроки:

**1. Налаштування оточення**
Скопіюйте файл конфігурації у кореневій папці проєкту:
`cp ./web/.example.env ./web/.env`
*(Обов'язково заповніть необхідні ключі у `.env` файлі)*

**2. Запуск інфраструктури (WordPress + MySQL)**
Підніміть контейнери через Docker:
`docker compose up -d`

**3. Імпорт бази даних (одноразово для розробки)**
Завантажте актуальний дамп бази даних:
`docker exec -i <назва_контейнера_бд> mysql -u wordpress -pwordpress wordpress < dump.sql`

**4. Запуск Frontend частини (Next.js)**
Оскільки локальна розробка фронтенду потребує гарячого перезавантаження (HMR), зупиніть `web` контейнер у Docker та запустіть його локально:
`cd ./web`
`npm install`
`npm run dev`

Проєкт буде доступний за адресою: `http://localhost:3000`
